# 阶段二独立PDF报告

本目录包含按附录A分别撰写的18份独立PDF：每个任务一份漏洞报告（VULN）和一份安全加固报告（FIX）。

## 文件对应关系

- `VULN-01` 至 `VULN-09`：漏洞报告
- `FIX-01` 至 `FIX-09`：安全加固报告

编号与任务顺序一致：

1. 弱口令与密码爆破
2. SQL注入
3. XSS跨站脚本
4. CSRF跨站请求伪造
5. 越权访问、IDOR与文件读取
6. 文件上传、WebShell与木马文件识别
7. SSTI模板注入
8. 命令执行与Shell调用
9. 会话管理、登出与Cookie安全

报告中的“测试小组”“修复负责人”等字段保留了“待填”标记，需要在课程提交前替换为真实信息。任务九外部截图和视频已归档在 `../evidence/task9/`，其他截图在 `../evidence/screenshots/`。
